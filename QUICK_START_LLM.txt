═══════════════════════════════════════════════════════════════
  PosterO with LLM - Quick Start Commands
═══════════════════════════════════════════════════════════════

STEP 1: Install Dependencies
─────────────────────────────────────────────────────────────
pip install vllm huggingface-hub


STEP 2: Download Model (Choose ONE)
─────────────────────────────────────────────────────────────

Option A - Mistral 7B (RECOMMENDED - No approval needed)
─────────────────────────────────────────────────────────────
huggingface-cli download mistralai/Mistral-7B-Instruct-v0.2 --local-dir ./models/mistral-7b


Option B - LLaMA 3.1-8B (Best quality, requires Meta approval)
─────────────────────────────────────────────────────────────
# 1. Login first
huggingface-cli login

# 2. Download (after approval)
huggingface-cli download meta-llama/Meta-Llama-3.1-8B-Instruct --local-dir ./models/llama-3.1-8b


Option C - Qwen 7B (Alternative, no approval)
─────────────────────────────────────────────────────────────
huggingface-cli download Qwen/Qwen2-7B-Instruct --local-dir ./models/qwen-7b


STEP 3: Test Installation
─────────────────────────────────────────────────────────────
python demo_postero_llm.py


STEP 4: Use in Your Code
─────────────────────────────────────────────────────────────

Python Code:
───────────
from src.postero_pipeline import PosterOPipeline
from PIL import Image

# Initialize with LLM
pipeline = PosterOPipeline(
    llm_path="./models/mistral-7b",  # or llama-3.1-8b, qwen-7b
    canvas_size=(720, 1080),
    use_official=True
)

# Generate layout
image = Image.new('RGB', (720, 1080), 'white')
layout = pipeline.generate_layout(image, "cyberpunk neon city", num_elements=3)

# Save template
template = pipeline.layout_to_template(layout)
pipeline.save_template(template, "templates/my_layout.json")


STEP 5: Use with Key2Poster
─────────────────────────────────────────────────────────────

Python Code:
───────────
from src.pipeline import Key2PosterPipeline

# Generate poster using PosterO layout
pipeline = Key2PosterPipeline(use_flux=True)
image, brief, metrics = pipeline.generate_poster(
    "cyberpunk neon city",
    template_path="templates/my_layout.json",
    output_path="outputs/poster.png"
)

  System Requirements
═══════════════════════════════════════════════════════════════

GPU:     NVIDIA with 16GB+ VRAM (RTX 3090/4090 recommended)
RAM:     32GB+ recommended
Storage: ~20GB for model files
OS:      Windows/Linux with CUDA support


═══════════════════════════════════════════════════════════════
  Troubleshooting
═══════════════════════════════════════════════════════════════

Problem: "CUDA out of memory"
Solution: Use smaller model (Mistral 7B) or reduce batch size

Problem: "vLLM not found"
Solution: pip install vllm --no-cache-dir

Problem: "Model not found"
Solution: Check model path exists: dir models\mistral-7b

Problem: "Permission denied"
Solution: Run: huggingface-cli login (get token from huggingface.co)
