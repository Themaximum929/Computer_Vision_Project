CINEMATIC TEXT OVERLAY - INTEGRATION TESTING GUIDE

OPTION 1: TEST WITH EXISTING POSTERS
=====================================

If you already have generated posters in outputs/:

1. Run integration test:
   python test_poster_integration.py

   This will:
   - Find existing posters in outputs/
   - Apply 5 different genre styles
   - Test font categorization
   - Save results to outputs/integration_test/

2. Check results:
   - Open outputs/integration_test/
   - Compare different genre styles
   - Verify text is readable and well-positioned

3. Features to test:
   ✓ Auto-adapt colors (toggle on/off)

   ✓ Font category (serif/sans-serif/display/decorative)
   ✓ Manual font selection
   ✓ Font size slider
   ✓ Color RGB sliders

   ✓ Stroke width
   ✓ Shadow offset
   ✓ Letter spacing

WHAT TO VERIFY:
===============

✓ Font Selection:
  - Epic/Drama → Serif fonts
  - Sci-Fi/Modern → Sans-Serif fonts
  - Action → Display fonts
  - Horror/Fantasy → Decorative fonts

✓ Color Adaptation:
  - Dark backgrounds → Bright text
  - Bright backgrounds → Dark text
  - Genre colors applied correctly

✓ Readability:
  - Text has appropriate stroke
  - Shadow provides depth
  - Text stays within bounds
  - No clipping at edges

✓ Effects:
  - Bold genres have heavier effects
  - Subtle genres have lighter effects
  - Effects scale with background brightness

TROUBLESHOOTING:
================

Issue: "No posters found"
Solution: Generate a poster first:
  python run_pipeline.py "dark fantasy" --genre-lora --seed 123

Issue: "No fonts found"
Solution: 
  - Add .ttf or .otf fonts to fonts/cinematic/
  - System will fallback to system fonts if none found

Issue: Text not visible
Solution:
  - Enable auto_adapt=True
  - Increase stroke_width
  - Increase shadow_offset
  - Try different position

Issue: Font not loading
Solution:
  - Check font file is .ttf or .otf
  - Verify file is in fonts/cinematic/
  - Check file permissions
  - Try system fonts (arial, times, impact)
