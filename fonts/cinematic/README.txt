CINEMATIC FONTS DIRECTORY

Place your .ttf or .otf font files here for use in the text overlay system.

Recommended cinematic fonts:
- Impact (bold action titles)
- Times New Roman (elegant drama)
- Arial Bold (modern clean)
- Bebas Neue (cinematic posters)
- Montserrat Bold (contemporary)
- Oswald (condensed impact)

Supported formats: .ttf, .otf

The system will automatically scan this directory and make fonts available in the UI.
If no fonts are found, it will fallback to system fonts.
