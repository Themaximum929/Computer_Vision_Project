================================================================================
TECHNICAL DETAILS
================================================================================

Implementation: src/diffusion_text_overlay.py
- DiffusionTextOverlay: Main FLUX text renderer
- HybridTextOverlay: Smart fallback system
- ControlNetTextOverlay: Precise placement (optional)

How it works:
1. Generate base poster without text
2. Use FLUX to generate text directly in image
3. Text prompt includes genre-specific styling
4. Result: naturally integrated typography

Performance:
- GPU (RTX 3090): ~5-8 seconds
- GPU (RTX 2060): ~10-15 seconds
- Requires: FLUX.1-schnell model (already installed)
